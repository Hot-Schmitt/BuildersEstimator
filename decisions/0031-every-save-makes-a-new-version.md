## Decision

Manual edits happen on screen, and every save is kept as a new version of the estimate,
so nothing is overwritten and the system gets each updated copy. This was the rule in
shared format 0.4.

## Why

The instinct was sound: nothing he changes is lost, and every edit is recoverable and
available to learn from.

## Considered instead

Nothing else was on the table when this was set. It was replaced on 2026-11-17 by
decision 0001, once saving became automatic: a version for every save treats a keystroke
and a milestone as the same thing, and ten pricing documents would have left ten
versions.

## What it costs us

None now; kept as the record of the rule decision 0001 replaced. The learning it was for
is carried by the change list inside each version.
