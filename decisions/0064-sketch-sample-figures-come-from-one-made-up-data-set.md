## Decision

Sample figures in a sketch come from one small made-up data set, added up in code, so
every count and total on the drawing agrees with every other.

## Why

Twice, sample figures typed by hand disagreed with each other: the first estimate screen
sketch showed totals that did not add up, and a laptop sketch said a division had 24
line items while its own groups added to 23. On an estimating tool, a drawing that does
not add up costs trust.

## Considered instead

**Typing plausible sample numbers into each drawing.** What was done both times.

## What it costs us

A small data set and a script to keep beside the drawings.
