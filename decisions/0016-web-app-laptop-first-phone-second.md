## Decision

The estimate is a web app. Its layout is designed for a laptop first; the phone layout
is a second pass. A division shows its own groups of line items, and modern icons help
him spot key things quickly.

## Why

The owner asked for a web layout that is more modern and not cumbersome for entering
prices and seeing categories. Entering prices line by line is laptop work.

## Considered instead

**Phone-width screens first.** Three phone-width sketches of the estimate screen were
drawn first and set aside on 2026-11-16 at 10:45 pm, when laptop-first was locked. The
third sketch's code was not saved; it is redrawn from its description when the phone
pass starts.

## What it costs us

The phone layout does not exist yet. The project instructions still say "phone and print
ready", which this order postpones for the phone.
